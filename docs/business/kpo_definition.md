# KPI Definition

| KPI | Formula |
|------|----------|
| Revenue | Sum(Sales Amount) |
| Profit | Revenue - Cost |
| Margin | Profit / Revenue |
| Average Order Value | Revenue / Orders |
| Total Orders | Count(Order ID) |
| Customer Count | Distinct Customer |
| Repeat Customer | Customer dengan >1 transaksi |
| Sales Growth | (Current - Previous)/Previous |
| Return Rate | Returned / Sold |
| Inventory Turnover | COGS / Average Inventory |
