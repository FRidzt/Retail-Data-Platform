# Business Requirement

## Project Name

Retail Data Intelligence Platform

---

## Company Background

ABC Retail adalah perusahaan retail nasional yang memiliki banyak cabang di berbagai kota.

Perusahaan ingin membangun platform data modern agar seluruh keputusan bisnis didasarkan pada data.

---

## Current Problems

- Data masih berupa file Excel/CSV
- Laporan dibuat manual
- Dashboard tidak real-time
- Tidak ada prediksi penjualan
- Sulit mengetahui performa tiap toko
- Data tersebar di banyak file

---

## Objectives

Membangun platform data modern yang mampu:

- Mengintegrasikan seluruh data retail
- Mengotomatisasi ETL
- Menyediakan Data Warehouse
- Menyediakan Dashboard
- Menyediakan Prediksi Penjualan

---

## Stakeholders

- CEO
- Sales Manager
- Finance Manager
- Marketing Manager
- Regional Manager
- Inventory Manager

---

## Success Criteria

- Dashboard otomatis
- ETL berjalan otomatis
- KPI selalu update
- Forecast tersedia
