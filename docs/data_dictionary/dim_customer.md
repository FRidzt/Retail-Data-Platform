# Dimension Customer

| Column | Data Type | Description |
|---------|-----------|-------------|
| customer_key | INTEGER | Surrogate Key |
| customer_code | VARCHAR(10) | Business Key |
| first_name | VARCHAR(50) | Customer First Name |
| last_name | VARCHAR(50) | Customer Last Name |
| gender | VARCHAR(10) | Male / Female |
| birth_date | DATE | Birth Date |
| email | VARCHAR(100) | Email Address |
| phone | VARCHAR(30) | Phone Number |
| city | VARCHAR(50) | City |
| province | VARCHAR(50) | Province |
| membership | VARCHAR(20) | Membership Level |
| segment | VARCHAR(20) | Customer Segment |
| register_date | DATE | Registration Date |
| is_active | BOOLEAN | Active Status |
